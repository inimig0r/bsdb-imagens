# 🎴 Battle Scenes Database - Repositório de Imagens

Este repositório é um arquivo comunitário dedicado a hospedar e preservar as imagens, artes, cards e ícones do card game **Battle Scenes**, além de conteúdos criados por fãs.

Como o jogo foi oficialmente descontinuado, o objetivo deste projeto é manter esses recursos acessíveis para a comunidade de jogadores, desenvolvedores de ferramentas comunitárias, plataformas de jogo online e entusiastas do jogo.

---

## 📁 Organização do Repositório

A estrutura de diretórios foi organizada de acordo com as coleções oficiais/fanmade do jogo. As pastas coleções oficiais são iniciadas em "bs", como "bsca", que corresponde à coleção Confronto Aracnídeo. As pastas das coleções fanmade [Excelcior](https://ligabspoa.wordpress.com/) são iniciadas em "fm", como "fmbsui", que corresponde à coleção fanmade União Inabalável:

```
.
├── bsca/                  # Confronto Aracnídeo
├── bsaq/                  # Ascensão e Queda
├── ...
├── fmbsui/                  # União Inabalável (fanmade)
├── fmbsfa/                # Filhos do Átomo
├── ...
├── artes/                   # Ilustrações, artes, embalagem de boosters, materiais publicitários, etc.
├── ...
└── README.md
```

## 🚀 Como Utilizar

Você pode consumir as imagens diretamente utilizando a CDN pública do GitHub (`raw.githubusercontent.com`).

### Exemplo de uso via URL direta:

```
https://raw.githubusercontent.com/inimig0r/bsdb-imagens/main/cards/NOME_DA_PASTA/CARD.png
```

Por exemplo, 
```
https://raw.githubusercontent.com/inimig0r/bsdb-imagens/refs/heads/main/bsaq/BSAQ_001.png
```
corresponde ao card Fantasma do Espaço (BSAQ_001), 1/112 da coleção Ascensão e Queda (bsaq).
